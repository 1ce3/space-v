# Bản Core tạm của B

Bốn file `.cs` trong thư mục này là bản chép nguyên văn `AGENTS.md` mục 7, chỉ để B viết và biên dịch thử trước khi C xong việc C0.

**Xoá cả thư mục này ngay khi `core/` của C có trên `main`.** Nếu để lại, project sẽ lỗi build vì trùng kiểu trong namespace `RocketGame.Core`.

Không sửa các file này. Cần đổi gì ở Core thì báo C.
