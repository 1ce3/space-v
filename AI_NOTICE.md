# AI Use Notice — Project: Icarus

**Team:** The Neptunians · **Event:** NASA Space Apps Challenge · **Challenge:** Space Mission Game Design

Some parts of this project were made with help from AI tools. Every AI output was reviewed, tested and edited by the team, and the team takes responsibility for it.

## AI-assisted work

| Area | Tool | What it did |
|---|---|---|
| Game code (C#) | Claude (Anthropic) | Wrote or co-wrote UI screens (hub, pause menu, HUD widgets, build panels), physics/thermal tuning, Mars terrain bending, camera limits, engine model/VFX wiring, tests. Files carry a `// AI-assisted` header comment. |
| In-game text | Claude (Anthropic) | Translated the game from Vietnamese to English; helped draft story and tutorial text. |
| Sound | Claude (Anthropic) | `assets/audio/explosion.wav` is an AI-generated placeholder (synthesized noise, no samples). The file's metadata says so. |
| Engine balance | Claude (Anthropic) | Scaled thrust values from real engine data (formula in `docs/API_CHANGES.md`). |
| Presentation deck | Claude (Anthropic) | Drafted the 7 project slides; each slide carries an AI notice in its footer. |

## Not AI-made

- 3D models, cutscene videos, thrust/explosion VFX and engine sound were made by the team, unless listed above.
- Real-world data (atmosphere, radiation, Mars) comes from NASA public sources.
